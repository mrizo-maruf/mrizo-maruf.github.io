# Notes from ICRA ACT to Sense to Act Better workshop

### Oliver Brock: A Programming Language for Interactive Perception and Robust Behavior in the Real World

#### No Plan but Everything Under Control — ICRA 2025 Paper Summary

Paper/project page: <https://rbo.gitlab-pages.tu-berlin.de/papers/mengers-icra-25/>

Paper title:

**No Plan but Everything Under Control: Robustly Solving Sequential Tasks with Dynamically Composed Gradient Descent**

Authors:

**Vito Mengers and Oliver Brock**, TU Berlin / RBO Lab.

##### 1. What is this paper about?

This paper proposes a robotics control method for solving **sequential tasks** without relying on an explicit symbolic plan.

The main idea is:

> Instead of computing a full plan like “first do A, then B, then C,” the robot continuously estimates the current situation and follows the most useful gradient toward task completion.

The method is called **AICON**, short for **Active InterCONnect**.

It uses a network of state estimators and active relationships between them. These relationships change depending on the current state of the task. Because of this, subgoals can emerge automatically.

For example, in a drawer-opening task, the robot may automatically switch between:

- looking for the handle,
- moving closer to the handle,
- grasping the handle,
- pulling the drawer,
- recovering if the handle is lost or the drawer is disturbed.

The important point is that these steps are **not written as an explicit fixed plan**. They emerge from the current state, uncertainty, and gradients.

##### 2. Which problem is it solving?

The paper addresses the problem of **long-horizon sequential robot behavior under uncertainty and disturbances**.

Robots often need to complete tasks that involve several steps. For example:

- stack blocks in a target arrangement,
- open a drawer,
- manipulate objects when their positions are uncertain,
- recover after a perception or grasping failure.

Traditional planning approaches usually require a relatively clear model of the world and a discrete sequence of actions. But in real robotics, this is hard because:

- perception is noisy,
- the environment changes,
- the robot may fail to grasp,
- the object may move unexpectedly,
- state estimation can be uncertain,
- plans can become invalid after small disturbances.

This paper tries to solve such tasks in a more **reactive and feedback-driven** way.

##### 3. How does it solve the problem?

The method builds a dynamically connected network of components.

###### 3.1 Estimators

Estimators represent the robot’s current belief about the world.

Examples:

- position of the robot hand,
- position of a drawer handle,
- whether the handle is visible,
- whether the handle is grasped,
- direction of the drawer joint,
- uncertainty of an object pose.

###### 3.2 Active interconnections

The relationships between estimators are not fixed. They can become active or inactive depending on the current situation.

For example:

- If the handle is not visible, the system creates behavior that moves the camera to find it.
- If the handle is visible, the system creates behavior that moves the hand toward it.
- If the handle is grasped, the system creates behavior that pulls the drawer.
- If the grasp is lost, the system can return to perception and recovery behavior.

###### 3.3 Gradient descent

The system defines a goal cost and computes gradients through the current network.

The robot then follows the most useful gradient at the current moment.

This is why the title says:

> **No Plan but Everything Under Control**

The robot does not need a precomputed task plan. Instead, its behavior is continuously generated by the structure of the current estimation network and the gradients inside it.

##### 4. Why is this useful?

This approach is interesting because it tries to combine the strengths of two different robotics paradigms.

###### Planning

Planning is good for long sequences of actions.

But planning can be brittle when the real world changes or when the state estimate is uncertain.

##### Reactive control

Reactive control is robust because it uses feedback at every moment.

But simple reactive controllers usually struggle with multi-step tasks.

##### This paper’s idea

The paper tries to make reactive gradient-based control powerful enough for sequential tasks.

Instead of planning the whole future, the robot continuously asks:

> Given what I know right now, what action most directly improves the task?

This can make the robot more robust to disturbances because it does not depend on a single fixed plan.

#### 5. Difference from current methods

| Method | Main idea | Weakness | Difference in this paper |
|---|---|---|---|
| Classical task planning | Search over symbolic states and actions | Can fail when the real world differs from the planned model | No explicit symbolic plan is required |
| Motion planning | Compute a path or trajectory to a goal | Often assumes reliable state and environment model | Behavior is continuously recomputed from feedback |
| Trajectory optimization | Optimize a future trajectory | Can be expensive and sensitive to model mismatch | Uses local gradients from the current state |
| Belief-space planning | Plan while accounting for uncertainty | Usually computationally expensive in high dimensions | Handles uncertainty through estimator networks and feedback |
| Behavior trees / FSMs | Manually define behaviors and transitions | Requires hand-written task logic | Sequential behavior emerges from active interconnections |
| Standard potential fields | Follow a gradient to a goal | Can get stuck and usually handles only simple tasks | Potential fields are dynamically composed depending on the task state |

#### 6. Example: drawer opening

In a drawer-opening task, a traditional system may require an explicit sequence:

1. detect handle,
2. move to handle,
3. grasp handle,
4. estimate drawer direction,
5. pull drawer,
6. check success,
7. recover if failure.

In this paper’s approach, these behaviors emerge from the active network.

Possible behavior:

1. The handle is uncertain.
2. The gradient makes the robot move its camera to improve visibility.
3. Once the handle is detected, the gradient moves the hand toward it.
4. Once the hand is close, grasping becomes the active behavior.
5. Once the handle is grasped, pulling along the drawer axis becomes active.
6. If the handle is lost or disturbed, the system returns to a perception/recovery behavior.

So the robot behaves as if it has a plan, but the sequence is generated online.

#### 7. Example: Blocks World

The paper also demonstrates the method on Blocks World.

Blocks World is a classical symbolic planning benchmark. A robot or agent needs to move blocks from one configuration to another.

Example:

Initial state:

```text
A on table
B on table
C on A
```

Goal state:

```text
A on B
B on C
C on table
```

A classical planner would search over possible block-moving actions.

This paper shows that a gradient-based method can also solve many such sequential tasks by encoding the structure of the task into differentiable components.

#### 8. Main contribution

The main contribution is not just “using gradient descent.”

The interesting part is:

> The task structure is represented as dynamically composed differentiable relationships, so sequential behavior can emerge without explicit planning.

This means the robot can act robustly in changing situations while still completing multi-step tasks.

#### 9. Limitations

The method does not fully replace planning.

The authors note that some tasks still require more explicit reasoning about the future.

Examples include tasks where:

- the robot must temporarily move away from the goal,
- subgoals conflict with each other,
- actions are irreversible,
- solving the task requires foresight,
- the task has puzzle-like structure, such as Towers of Hanoi.

In such cases, pure gradient-based behavior may not be enough.

#### 10. Short summary

This paper proposes a feedback-driven alternative to explicit planning for sequential robot tasks.

Instead of computing a full action sequence in advance, the robot continuously estimates the world and follows the most useful gradient. The method dynamically composes relationships between estimators, allowing subgoals like perception, grasping, pulling, and recovery to emerge automatically.

It is especially useful for robust manipulation under uncertainty, but it may still need to be combined with planning for tasks that require long-term foresight or irreversible decisions.
